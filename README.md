# LarpBlocker
Chrome MV3 Ext to larp having an extension filter

## Use of Generative AI
I used generative AI to create and expand the blocklist.json file since putting the sites in individually would be a massive time-consumer.

Other files were human-made by me!

## Customize allowed and blocked sites

Open the extension settings from its toolbar button. Add a site to either list,
remove it, or edit the reason shown for a blocked site. Changes are saved in
extension storage and apply to the next top-level navigation. Adding a site to
one list removes the same host from the other list. Sites not on the allowlist
remain blocked as unknown.
